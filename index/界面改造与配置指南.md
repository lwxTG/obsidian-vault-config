## 二、Style Settings 可调整项（重点）

入口：`设置 → 外观 → Style Settings`（面板标题为英文）。以下为当前预设值与调整效果：

| 面板路径 | 选项 | 当前值 | 调整效果 |
|---|---|---|---|
| General → Background images → Workplace background image | Activate image background | 关 | 开 = 工作区显示背景图 |
| General → Background images → Note page background image | Toggle note background image | 关 | 开 = 笔记页显示背景图 |
| General → Layout → Bubble settings | Toggle bubble buttons | 关 | 开 = 侧边悬浮气泡按钮 |
| Detail → Element styles → Folder → Colorful folder | Toggle colorful folders | 关 | 开 = 文件树彩色文件夹 |
| Detail → Element styles → Highlights | Deactivate colorful-highlight | 开 | 关 = 恢复彩色高亮 |
| Detail → Element styles → List → Indentation lines | (Hovering) 彩色缩进线 | 关 | 开 = 悬停显示彩色缩进线 |
| Detail → Element styles → List → Indentation lines | (Reading) 彩色缩进线 | 开 | 关 = 阅读模式无缩进线 |
| Detail → Typography → Font family | Main font | Noto Sans SC 系列 | 换正文默认字体 |
| Detail → Typography | Line height（行距） | 1.6 | 调行距（1.5–1.8 舒适区） |
| Detail → Typography | Alignment of both ends（两端对齐） | 开 | 关 = 取消两端对齐 |

### 想恢复"改造前丰富的颜色"？

按以下组合开启（即还原 Blue Topaz 的完整彩色风格）：

1. **彩色文件夹**：Element styles → Folder → Colorful folder → 开启
2. **彩色高亮**：Element styles → Highlights → Deactivate colorful-highlight → 关闭
3. **彩色缩进线**：Element styles → List → Indentation lines (Hovering) → 开启
4. **背景图**：General → Background images → 工作区/笔记页背景 → 开启
5. **气泡按钮**：General → Layout → Bubble settings → 开启

**最快还原法**：直接删除 `.obsidian/plugins/obsidian-style-settings/data.json`，重启后主题回到 Blue Topaz 出厂默认（所有选项默认值）。

### 界面三色微调（color-tweak.css）

界面文字三色的来源与调整：

| 颜色 | 变量 | 定义处 | 当前值 |
|---|---|---|---|
| 黑（正文） | `--text-normal` | Blue Topaz 主题（面板可改：Color settings → Main text color） | `#0e0e0e` |
| 蓝（链接） | `--link-color` / `--internal-link-color` 等 | Obsidian 默认 / 主题 | `#0969da`（GitHub 蓝） |
| 橙（行内代码） | `--text-color-code` | Blue Topaz 主题（无面板项） | `#476582`（蓝灰，原为 `#e95d00`） |

- **修改文件**：`.obsidian/snippets/color-tweak.css`（body 级 `!important` 覆盖变量，因主题变量定义在 `body.theme-light` 等更高优先级作用域）
- **想换其他颜色**：直接改该文件里的色值，然后在外观 → CSS 片段点刷新
- **恢复原样**：设置 → 外观 → CSS 片段 → 关闭 `color-tweak`（或 CLI `obsidian snippet:disable name=color-tweak`）——链接回天蓝、行内代码回亮橙，正文不变
- **注意**：新增/修改 CSS 片段后 Obsidian 不会自动加载，需在"外观 → CSS 片段"点刷新（或 CLI `obsidian snippet:enable name=xxx`）

## 三、字体与字号

| 设置   | 当前值                   | 修改入口                                                              |

| 正文字体 | Noto Sans SC → 微软雅黑回退 | Style Settings → Typography → Font family                         |

## 四、首页可调内容（`index/🔖-首页.md`）

- **面板条数**：dataviewjs 中 `limit(8)` / `limit(10)` 等参数（最近更新 8 条、任务 10 条等）
- **待办任务来源**：`dv.pages('"kanban" or "work"')`——只统计看板与便签目录；若想纳入全部笔记任务，改成 `dv.pages('')`
- **统计数字**：统计条四个卡片（笔记总数/近 7 天更新/未完成任务/工作便签）在 dataviewjs 头部数据区
- **快速入口**：页面下方 callout 卡片，直接改 markdown 链接
- **样式**：`.obsidian/snippets/home.css`（统计条、面板、卡片圆角与间距，全部使用主题 CSS 变量）

## 六、目录与附件规范（维护约定）

- **目录分工**：`index/` 导航元信息 · `notes/` 工作笔记 · `archive/guides/` 归档指南 · `archive/<topic>/` 专题归档 · `study/` 学习 · `work/` 便签 · `kanban/` 看板 · `clippings/` 摘录 · `resource/` 资源 · `scripts/` 脚本
- **附件规则**：`resource/attachments/<笔记名>/`（插件自动按笔记名建目录；飞书下载默认落 `resource/attachments/<doc-slug>/`，注意保持与笔记名一致）
- **自动检查**：说"检查仓库"触发 vault-lint（含 ATT001 附件目录一致性规则）；或打开 `index/笔记总览.md` 看"附件体检"面板

## 七、回滚方式

| 场景 | 操作 |
|---|---|
| 还原任意一次改动 | `git log` 找对应 commit，`git checkout <commit> -- <文件>` |
| 整体还原到改造前 | `git reset --hard 3de0231` |
| 配置双保险 | 解压 `backup/obsidian-config-20260813.zip` 覆盖 `.obsidian/` |
